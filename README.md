# 🔗 URL Shortener

A simple and efficient URL Shortener web application built using Node.js, Express, and MongoDB. It allows users to convert long URLs into short, shareable links and redirect seamlessly.

---

##  Features

*  Shorten long URLs into compact links
*  Redirect users to original URLs
*  Stores data in MongoDB database
*  Clean and structured MVC architecture
*  Simple UI using EJS templates

---

##  Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* EJS
* dotenv
